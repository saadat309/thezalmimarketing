# Zalmi staging web

This is an isolated TanStack Start + Cloudflare Workers frontend preview. It reuses the repository's homepage/static-page design and reads public listing/detail examples through server-side GET calls to the separate synthetic API in `apps/ssr-spike/`. It does not import the legacy API client or connect to cPanel, production MySQL, production media, or the existing PHP API. Listing imagery remains a clearly labeled local placeholder; property media storage is deferred. Contact and newsletter forms are disabled. The frontend Cloudflare configuration is local-preview-only and has no bindings or deploy script.

Run the synthetic API from `apps/ssr-spike/` on `127.0.0.1:4175`, then run this app from its directory with `npm run dev` (default `127.0.0.1:4174`). Build with `npm run build`. For a local production-style preview, build with `VITE_STAGING_API_ORIGIN=http://127.0.0.1:4175` before starting `npm run preview`; otherwise a non-development build targets the previously approved hosted property-only synthetic API. This origin is configuration, not a secret. The previous hand-built Vite replica remains in `src/App.jsx` and is no longer the application entry point. The local server-function fetch uses `redirect: 'manual'`, as required by the Workers runtime; redirects and other non-success API responses are treated as unavailable rather than followed.

Generated TanStack route-tree/type files may use TypeScript only as allowed by ADR-012; application code remains JavaScript/JSX. Unmatched routes render the staging not-found page and should return HTTP `404` from the Start runtime.
